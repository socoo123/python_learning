## 🔖 闪卡

| # | 正面(问题) | 背面(答案) | 掌握 |
|---|---|---|---|
| 1 | `re.search` / `match` / `fullmatch` 区别?对应 Java 什么? | search=任意位置第一个(Java `find()`);match=只从头(Java 无对应);**fullmatch=整串(Java `matches()`)**。校验输入用 fullmatch | ⬜ |
| 2 | Python 命名分组怎么写?和 Java 差哪? | `(?P<name>...)`——比 Java `(?<name>...)` **多个大写 P**。`m.groupdict()` 一次导出全部命名分组为 dict | ⬜ |
| 3 | 为什么正则字面量必须加 `r` 前缀? | 正则的 `\d` `\b` 不是合法 Python 转义,不加 `r` 会警告;匹配字面 `\` 时 `'\\\\'` vs `r'\\'`。**正则一律原始字符串** | ⬜ |
| 4 | `findall` 的模式里有捕获分组 `(...)` 会怎样?怎么规避? | 返回值变成【分组内容】而非整个匹配。只为重复/分组就用**非捕获分组 `(?:...)`** | ⬜ |
| 5 | `re.sub` 的三种替换形态?各适合什么? | ①固定串(与匹配无关)②反向引用 `\g<1>`/`\g<name>`(替换=匹配的子集)③函数 `lambda m: ...`(替换要计算) | ⬜ |
| 6 | 反向引用为什么推荐 `\g<1>` 而不是 `\1`?和 Java 差哪? | `'\10'` 被解读成「第 10 组」而非「第 1 组+0」,`\g<1>` 无歧义。Java 用 `$1`,Python 用 `\1`/`\g<1>` | ⬜ |
| 7 | `re.split` 和 Java `String.split` 的尾部空串差异? | Java **悄悄丢弃**尾部空串;Python **保留**。Python 拆完习惯 `[... for s in re.split(...) if s]` 过滤 | ⬜ |
| 8 | 什么时候该 `re.compile` 预编译? | 用一次的正则直接 `re.xxx(...)`(内部缓存最近 512 个);循环反复用/模块级共享才 `compile` 存常量,图可读性 | ⬜ |
| 9 | 「str 方法 vs 正则」的选择原则? | 固定子串操作(in/startswith/split/splitlines/replace)用 str;**模式**匹配(IP/邮箱/日志结构)才上 re | ⬜ |
| 10 | f-string 对齐/千分位/百分比怎么写? | `{x:<16}` 左对齐宽 16、`{n:>5}` 右对齐、`{n:,}` 千分位、`{r:.1%}` 百分比。对应 Java `String.format("%-16s%5d")` | ⬜ |
| 11 | 贪婪 `.*` vs 非贪婪 `.*?`? | `.*` 尽量多吃(`<p>a</p><p>b</p>` 一把吞);`.*?` 尽量少。提取标签/引号内容用非贪婪 | ⬜ |
