## 🔖 闪卡

| # | 正面(问题) | 背面(答案) | 掌握 |
|---|---|---|---|
| 1 | Python 命名分组怎么写?和 Java 有何不同? | `(?P<name>...)`(注意大写 **P**)。Java 是 `(?<name>...)` 没 P。`m.groupdict()` 一次拿全命名分组 | ⬜ |
| 2 | `re.search` / `re.match` / `findall` 区别? | search 找【任意位置】第一个;match 只看【开头】;findall 找【所有】返回列表 | ⬜ |
| 3 | Python 正则字符串为什么要加 `r`? | 正则里的 `\d` `\w` 不是合法 Python 转义,不加 `r` 会警告。**正则一律用原始字符串 `r'...'`** | ⬜ |
| 4 | `re.sub` 和 `re.split` 各干嘛? | sub = 替换所有匹配(`re.sub(r'\d','#','a1')`→'a#');split = 按模式拆分(`re.split(r'[,;]','a,b;c')`→['a','b','c']) | ⬜ |
| 5 | `[^\]]+` 和 `\S+` 各匹配什么? | `[^\]]+` = 非 ] 的字符一个或多个(抓方括号内容);`\S+` = 非空白字符一个或多个(抓无空格的路径等) | ⬜ |
| 6 | `findall` 遇到分组会怎样? | 模式有分组时,findall 返回【分组元组】而非整个匹配。要整个匹配就别分组,或用 `(?:...)` 非捕获分组 | ⬜ |
| 7 | 贪婪 `.*` 和非贪婪 `.*?`? | `.*` 贪婪(尽量多匹配),`.*?` 非贪婪(尽量少)。提取 `<tag>...</tag>` 内容用 `.*?` 避免吃多 | ⬜ |
