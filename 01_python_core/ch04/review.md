## 🔖 闪卡

| # | 正面(问题) | 背面(答案) | 掌握 |
|---|---|---|---|
| 1 | `@deco` 贴在 `def f` 上面,等价于哪一句? | `f = deco(f)`——装饰器在【定义时】执行一次,把 f 替换成包装版 | ⬜ |
| 2 | 装饰器的 wrapper 为什么必须用 `*args, **kwargs`? | 为了接住【原函数任意签名】的调用,再原样 `func(*args, **kwargs)` 转发。写死参数就限制了原函数 | ⬜ |
| 3 | `@functools.wraps(func)` 干嘛的?不加会怎样? | 把原函数的 `__name__`/`__doc__` 等拷贝给 wrapper。不加的话装饰后 `f.__name__` 变成 `"wrapper"`,调试/反射乱套 | ⬜ |
| 4 | 带参数的装饰器(如 `@retry(times=3)`)要写几层?每层 return 什么? | **三层**:`factory(args)` return decorator;`decorator(func)` return wrapper;`wrapper` 是实际替换原函数的。等价 `f = retry(times=3)(f)` | ⬜ |
| 5 | 闭包是什么?为什么外层函数返回后,被捕获的变量还活着? | 内层函数 + 它记住的外层变量。内层函数持有外层变量的引用,只要内层函数还在,那些变量就不被回收。≈ Java lambda 捕获 effectively final | ⬜ |
| 6 | `*args` 和 `**kwargs` 在函数内分别是什么类型? | `*args` → **元组** tuple;`**kwargs` → **字典** dict | ⬜ |
| 7 | `func` 和 `func()` 的区别?(传参时常踩) | `func` 是函数【对象本身】(不调用);`func()` 是【调用】它得到返回值。传函数当参数要传 `func` 不带括号 | ⬜ |
