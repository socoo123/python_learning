## 🔖 闪卡

| # | 正面(问题) | 背面(答案) | 掌握 |
|---|---|---|---|
| 1 | 可变默认参数 `def f(x=[])` 的坑?正确写法? | 默认值在定义时**只创建一次**,所有调用共享同一个 list。正确:`def f(x=None)` + 函数内 `if x is None: x=[]` | ⬜ |
| 2 | 反转列表(不改原列表)一行代码? | `a[::-1]`(切片步长 -1) | ⬜ |
| 3 | dict 键不存在,`d[k]` 和 `d.get(k)` 区别? | `d[k]` 抛 `KeyError`;`d.get(k)` 返回 None(或 `d.get(k, default)`) | ⬜ |
| 4 | Python dict 从 3.7 起保证什么?相当于 Java 哪个类? | **插入有序** = Java `LinkedHashMap`(不是无序的 HashMap) | ⬜ |
| 5 | 两个 set 求交集/并集/差集,符号是? | `a & b` / `a | b` / `a - b` | ⬜ |
| 6 | 元组解包交换两个值怎么写? | `a, b = b, a`(无需临时变量) | ⬜ |
| 7 | 按 price 升序排商品,一行怎么写? | `sorted(products, key=lambda p: p["price"])` | ⬜ |
