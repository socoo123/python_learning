## 🔖 闪卡

| # | 正面(问题) | 背面(答案) | 掌握 |
|---|---|---|---|
| 1 | 判 `None` 用 `== None` 还是 `is None`?为什么? | `is None`;None 是单例对象,`is` 比身份(地址),`==` 比值 | ⬜ |
| 2 | Python 为什么需要虚拟环境(venv),Java 不用? | Python 全局共享 site-packages,同包不同版本互相覆盖;Java 依赖按项目隔离(Maven),全局只有一个 `java` | ⬜ |
| 3 | 类型注解 `def f(a: int)` 运行时会强制检查吗? | 不会。注解只是提示,运行时不强制;靠 `mypy` 静态检查模拟编译期 | ⬜ |
| 4 | Python 没有 `++`/`--`,自增怎么写? | `i += 1`(确实没有 ++/--) | ⬜ |
| 5 | Python 用什么表示代码块? | **缩进**(4 空格),不是花括号;混用 Tab/空格会 `IndentationError` | ⬜ |
