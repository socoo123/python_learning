## 🔖 闪卡

| # | 正面(问题) | 背面(答案) | 掌握 |
|---|---|---|---|
| 1 | 类型注解 `def f(a: int)` 运行时会强制检查吗?传错类型会怎样? | 不会。注解只是给人和 mypy 看的提示;运行时鸭子类型——传错类型要么照常算(如 str*int),要么炸在运算那一行 | ⬜ |
| 2 | `a, b = b, a` 为什么不需要临时变量? | 右边先整体求值打包成元组(相当于存快照),再解包给左边 | ⬜ |
| 3 | 函数怎么"返回多个值"?接收方怎么接? | `return x, y`(返回一个元组);接收方用 `a, b = f()` 解包 | ⬜ |
| 4 | 默认参数怎么替代 Java 方法重载?调用时有哪几种传法? | 签名里写 `currency="¥"`;位置传参 / 关键字传参(`currency="$"`)/ 省略用默认 | ⬜ |
| 5 | f-string 里价格保留 2 位小数怎么写? | `f"{price:.2f}"`(冒号开始格式说明,`.2f` = 定点 2 位) | ⬜ |
| 6 | 拼接多行字符串为什么用 `"\n".join(lines)` 而不是 `+=` 循环?主语是谁? | join 一次分配内存 O(n),`+=` 每次新建字符串 O(n²);主语是**分隔符**(Java 老手常写反) | ⬜ |
| 7 | 背 truthiness 真值表:哪些是 falsy? | 空(`""`/`[]`/`{}`/`()`)、零(`0`/`0.0`)、假(`False`)、None | ⬜ |
| 8 | `stock = 0` 时 `if stock:` 进分支吗?想区分"没填"和"填了 0"怎么写? | 不进(0 是 falsy);用 `if stock is not None:` | ⬜ |
| 9 | `str("hi")` 和 `repr("hi")` 分别得到什么?为什么日志里要用 repr? | `hi`(无引号)vs `'hi'`(带引号);repr 无歧义、能 eval 重建,区分值和变量名 | ⬜ |
| 10 | 拿到值的类型名字符串怎么写? | `type(obj).__name__`(≈ Java `getClass().getSimpleName()`) | ⬜ |
| 11 | Python 的 `import` 和 Java 的 `import` 本质区别? | Java 是编译期声明;Python 是运行时执行的语句(找到 .py 执行它,绑定名字) | ⬜ |
| 12 | 带过滤的列表推导式骨架?(对应 Java stream filter+map) | `[表达式 for 变量 in 可迭代对象 if 条件]` | ⬜ |
| 13 | `sum(...)`/`min(...)` 里喂 `(x for x in xs)` 和 `[x for x in xs]` 差在哪? | 括号是生成表达式,惰性、不建临时列表;方括号是列表推导式,真造一个 list | ⬜ |
| 14 | 判 `None` 用 `== None` 还是 `is None`?为什么? | `is None`;None 是单例,`is` 比身份,`==` 比值 | ⬜ |
| 15 | Python 为什么需要虚拟环境(venv),Java 不用? | Python 全局共享 site-packages,同包不同版本互相覆盖;Java 依赖按项目隔离(Maven) | ⬜ |
| 16 | `if __name__ == "__main__":` 的作用? | 直接运行文件时执行该块;被 import 时不执行——同一文件既能当脚本又能当库 | ⬜ |
