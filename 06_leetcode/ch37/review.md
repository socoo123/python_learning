## 🔖 闪卡

| # | 正面(问题) | 背面(答案) | 掌握 |
|---|---|---|---|
| 1 | Python 里用什么当栈?怎么 push/pop/peek? | 直接拿 `list` 当栈:`append`(push)、`pop`(pop)、`[-1]`(peek),都 O(1) 均摊。无需专门 Stack 类 | ⬜ |
| 2 | 为什么 `list.pop(0)` 不能当队列?队列该用什么? | `list.pop(0)` / `insert(0,x)` 是 O(n)(整段搬运)。队列/双端用 `collections.deque`,`append`/`popleft` 都 O(1) | ⬜ |
| 3 | 栈为什么天然适合括号配对? | LIFO(后进先出)正好对应「最近未闭合的左括号」。右括号配对的就是栈顶那个最近的左括号,栈还能保住正确嵌套顺序(`([)]` 非法) | ⬜ |
| 4 | is_valid_parens 的三个失败点? | ① 右括号来栈空(没左可配)② 栈顶不匹配(`(]`)③ 走完栈非空(左括号没闭合,如 `(`)。技巧:dict `{')':'('}` 反向映射 | ⬜ |
| 5 | MinStack 怎么 O(1) 取最小值? | 辅助栈 `mins` 与主栈**同步增减**;`push` 时 `mins.append(min(val, mins[-1]))`,`pop` 时两栈同步弹。`mins[-1]` 始终 = 当前最小 | ⬜ |
| 6 | 为什么 MinStack pop 同步弹就正确? | 辅助栈每层记录「到这层为止的最小值」。弹掉栈顶元素后,剩下最小值正好是辅助栈新栈顶(它记录的就是「到上一层为止的最小」)。两栈历史对齐 | ⬜ |
| 7 | 单调栈的核心思想?总复杂度? | 维护单调栈(递增/递减),新元素破坏单调就反复弹、弹时结算答案。每元素入/出栈至多一次 → **O(n)**(均摊,虽有嵌套 while) | ⬜ |
| 8 | LC739 daily_temperatures 的栈存什么?为什么? | 存**下标**(不是温度),栈内温度单调递减。答案要算距离 `i-j`,必须存下标。新温 > 栈顶就弹并 `ans[j]=i-j`;留在栈里的默认 0 | ⬜ |
| 9 | 单调栈模板举一反三改哪两处? | ① 比较符号 `>` 改 `<`(求下一个更小);② 存下标改存值。可解 LC496/503 下一个更大元素、LC42 接雨水 | ⬜ |
| 10 | 接雨水每根柱子的水怎么算? | `min(它左边最高, 它右边最高) - 自身高度`,取正部分。关键视角:从「整体接水」切到「逐列算」 | ⬜ |
| 11 | 接雨水双指针为什么正确?(矮侧定型) | `height[left]<height[right]` 时,第 left 根右侧必有 ≥ right 的柱子挡着,水位由 `left_max` 决定。**矮的那侧已定型**,处理它再移动 | ⬜ |
| 12 | 接雨水三种解法的空间? | 预处理左右 max 数组 O(n);单调栈 O(n);**对撞双指针 O(1)**(最优)。时间都是 O(n) | ⬜ |
| 13 | Java 老手在栈题上的两个坑? | ① 别用遗留 `Stack` 类(继承 Vector 全加锁,慢),用 `ArrayDeque`;② Java 装箱 `Integer` 比较用 `.equals` 别用 `==`,Python 无此问题 | ⬜ |
