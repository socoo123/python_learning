## 🔖 闪卡

| # | 正面(问题) | 背面(答案) | 掌握 |
|---|---|---|---|
| 1 | Python 里用什么当栈?怎么 push/pop/peek? | 直接拿 `list` 当栈:`append`(push)、`pop`(pop)、`[-1]`(peek),均摊 O(1)。无需专门 Stack 类 | ⬜ |
| 2 | 为什么 `list.pop(0)` 不能当队列?队列该用什么? | `list.pop(0)` / `insert(0,x)` 是 O(n)(整段搬运)。队列/双端用 `collections.deque`,`append`/`popleft` 都 O(1) | ⬜ |
| 3 | 栈为什么天然适合「配对/消除」类题? | LIFO(后进先出)= 「最近未闭合的先结算」。右括号配最近左括号、消消乐消最近同字符——遇栈顶结算,配不上就入栈等待 | ⬜ |
| 4 | is_valid_parens 的三个失败点? | ① 右括号来栈空(没左可配)② 栈顶不匹配(`(]`)③ 走完栈非空(`(` 没闭合)。技巧:dict `{')':'('}` 反向映射 | ⬜ |
| 5 | LC1047 相邻消除和 LC20 括号配对,骨架哪里一样? | 同一个「遇栈顶结算」模式:栈顶配得上(同字符/对应左括号)就弹出,否则入栈;LC1047 最后 `"".join(stack)` 即答案 | ⬜ |
| 6 | eval_rpn 遇运算符弹两个数,哪个是左操作数? | **后弹的才是左**:先 `b = stack.pop()`(右),再 `a = stack.pop()`(左),算 `a - b`。减/除顺序反了必错 | ⬜ |
| 7 | eval_rpn 的除法为什么写 `int(a / b)` 不写 `a // b`? | 题目要**向零取整**(Java 直觉);Python `//` 是**向下取整**,负数翻车:`-6 // 132 == -1` 而 `int(-6/132) == 0` | ⬜ |
| 8 | MinStack 怎么 O(1) 取最小值? | 辅助栈 `mins` 与主栈**同步增减**;`push` 压 `min(val, mins[-1])`,`pop` 两栈同步弹。`mins[-1]` 始终 = 当前最小 | ⬜ |
| 9 | 为什么 MinStack pop 同步弹就正确? | 辅助栈每层记录「到这层为止的最小值」。弹掉栈顶后,新栈顶正好是「到上一层为止的最小」——两栈历史完全对齐 | ⬜ |
| 10 | 用两个栈造队列,什么时候倒栈?为什么均摊 O(1)? | **只有 out 栈空了**才把 in 全倒过来。每元素一生「进 in、倒出、进 out、弹出」4 次,n 元素 4n 次 → 均摊 O(1) | ⬜ |
| 11 | MyQueue 的 empty 怎么判?常见错法? | `not in_stack and not out_stack`(两栈都空)。只看 in 会漏掉已倒进 out 还没弹的元素 | ⬜ |
| 12 | 单调栈的核心思想?总复杂度? | 维护单调栈(递增/递减),新元素破坏单调就反复弹、弹出时结算答案。每元素入/出栈至多一次 → **O(n)** 均摊(for 套 while 也是) | ⬜ |
| 13 | LC739 daily_temperatures 的栈存什么?为什么? | 存**下标**(不是值),栈内温度单调递减。答案要算距离 `i-j`,必须存下标。新温 > 栈顶就弹并 `ans[j]=i-j`;留下的默认 0 | ⬜ |
| 14 | 单调栈模板举一反三改哪两处? | ① 比较符号 `>` 改 `<`(求下一个更小);② 存下标改存值。可解 LC496/503 下一个更大、LC42 接雨水 | ⬜ |
| 15 | 接雨水每根柱子的水怎么算? | `min(它左边最高, 它右边最高) - 自身高度`,取正。关键视角:从「整体接水」切到「逐列算」 | ⬜ |
| 16 | 接雨水双指针为什么正确?(矮侧定型) | `height[left]<height[right]` 时,left 右侧必有 ≥ right 的柱子挡着,水位由 `left_max` 决定。**矮的那侧已定型**,处理它再移动 | ⬜ |
| 17 | 接雨水三种解法的空间? | 预处理左右 max 数组 O(n);单调栈 O(n);**对撞双指针 O(1)**(最优)。时间都是 O(n) | ⬜ |
| 18 | Java 老手在栈/队列题上的三个坑? | ① 别用遗留 `Stack` 类(继承 Vector 全加锁),用 `ArrayDeque`;② 装箱 `Integer` 比较用 `.equals` 别用 `==`;③ 带着 Java `/` 的直觉写 Python `//`——负数向零 vs 向下不同 | ⬜ |
