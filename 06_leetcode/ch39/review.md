## 🔖 闪卡

| # | 正面(问题) | 背面(答案) | 掌握 |
|---|---|---|---|
| 1 | DP 的本质一句话?和分治的区别? | 把大问题拆成子问题并**记住答案**避免重复计算。区别:分治子问题不重叠,DP 子问题大量重叠(斐波那契 f(3) 反复算) | ⬜ |
| 2 | 识别 DP 的三个信号?两个理论前提? | ① 求最值 ② 求方案数 ③ 求可行性。前提:最优子结构 + 无后效性 | ⬜ |
| 3 | DP 两把写法?Python 利器? | 自顶向下(记忆化递归 + `@lru_cache`)vs 自底向上(迭代填 `dp` 表)。Java 记忆化要手写 `int[] memo` 判 -1,Python 一行装饰器 | ⬜ |
| 4 | DP 四步套路? | ① 定义状态(带转移需要的信息)② 写转移方程 ③ 定边界+初始值(哨兵)④ 计算顺序+答案位置 | ⬜ |
| 5 | `@lru_cache` 能缓存什么参数? | 只能缓存**可 hash** 参数(int/str/tuple)。list 不可 hash → 转 tuple,或改缓存下标版 `f(i)` | ⬜ |
| 6 | 爬楼梯转移?为什么裸递归爆炸? | f(n)=f(n-1)+f(n-2),f(1)=1,f(2)=2。裸递归子问题重叠呈 O(2ⁿ);`@lru_cache` 缓存后 O(n) | ⬜ |
| 7 | 最大子数组和的状态定义?答案在哪? | dp[i]=**以 nums[i] 结尾**的最大和 = `max(x, dp[i-1]+x)`(负数前缀果断扔)。答案 = `max(dp)` 不是 `dp[-1]` | ⬜ |
| 8 | Kadane 全负数数组的坑? | best/cur 必须用 `nums[0]` 初始化;初始化成 0 会把「不许选空」错答成 0(如 [-2,-1] 应得 -1) | ⬜ |
| 9 | rob 的状态 + 转移?和爬楼梯的本质区别? | dp[i]=max(dp[i-1], dp[i-2]+nums[i-1])(选/不选)。爬楼梯求方案数用 `+`,rob 求最值用 `max` | ⬜ |
| 10 | rob 的贪心反例? | [2,1,1,2]:贪心见大就偷得 2+1=3,最优 2+2=4。局部最优 ≠ 全局最优 | ⬜ |
| 11 | coin_change 状态+转移? | dp[i]=凑成 i 的最少硬币数;dp[i]=min(dp[i-c]+1) for c in coins,c<=i;dp[0]=0 | ⬜ |
| 12 | coin_change 哨兵为什么是 amount+1?不可达返回什么? | 最优答案最多用 amount 个 1 元硬币,绝不超过 amount;amount+1 当「无穷大」。dp[amount]>amount → 返回 -1 | ⬜ |
| 13 | coin_change 为什么不能贪心? | 反例 [1,3,4] 凑 6:贪心 4+1+1=3 枚,最优 3+3=2 枚。贪心只看眼前会错过组合 | ⬜ |
| 14 | Python 负索引在 DP 里的坑? | `dp[i-c]` 忘判 `c<=i` 时下标变负,**不报错**而是静默绕到表尾(Java 数组越界直接炸),结果全错还难查 | ⬜ |
| 15 | LIS 的 dp[i] 定义?答案在哪? | dp[i]=**以 nums[i] 结尾**的 LIS 长;dp[i]=max(dp[j]+1) for j<i,nums[j]<nums[i];答案=max(dp)(如 [1,2,3,0] 答案 3 不在末尾) | ⬜ |
| 16 | LIS 严格 vs 非严格?进阶复杂度? | 严格用 `<`(全相等 [7,7,7,7] → 1),非递减才 `<=`。进阶:bisect 维护 tails,O(n log n) | ⬜ |
| 17 | unique_paths 转移 + 边界?数学秒杀式? | dp[i][j]=上+左;第一行/列全 1(只有一种走法)。数学:`math.comb(m+n-2, m-1)` | ⬜ |
| 18 | Python 写二维 DP 表的大坑? | `[[0]*w]*h` 是浅拷贝,所有行同一对象,改一格整列变。必须 `[[0]*w for _ in range(h)]`。Java `new int[][]` 没这问题 | ⬜ |
| 19 | LCS 的状态 + 转移? | dp[i][j]=text1 前 i × text2 前 j 的 LCS 长。相等 dp[i-1][j-1]+1;否则 max(dp[i-1][j], dp[i][j-1])。表开 (len1+1)x(len2+1),字符用 [i-1] 对齐 | ⬜ |
| 20 | 编辑距离三操作对应表的哪三个邻居? | 删除=上方 dp[i-1][j];插入=左方 dp[i][j-1];替换=左上 dp[i-1][j-1]。不等时 1+min(删,插,替) | ⬜ |
| 21 | 编辑距离字符相等时为什么不 +1? | 相等「白嫖」,这对字符已匹配不需操作,直接继承左上角代价。不等才 +1。相等也 +1 会把 ("abc","abc") 错答 3 | ⬜ |
| 22 | 编辑距离边界 dp[i][0]/dp[0][j]?漏了会怎样? | dp[i][0]=i(全删),dp[0][j]=j(全插)。漏填默认 0,("abc","") 错答 0(正确 3) | ⬜ |
| 23 | DP 空间优化通用技巧? | 滚动数组:只依赖「前一个/上一行」就压掉整表。爬楼梯/rob/Kadane O(1),LCS/编辑距离 O(min(m,n)) | ⬜ |
