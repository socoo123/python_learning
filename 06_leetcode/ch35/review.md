| 1 | 双指针三种形态?各适合什么题? | ① 对撞(相向:有序找 pair / 盛水 / 三数之和)② 快慢(同向:原地分区,移动零/去重)③ 滑动窗口(同向夹区间:无重复子串/最短子数组/最小覆盖) | ⬜ |
| 2 | 双指针为什么能省时间? | 朴素枚举 (i,j) 对 O(n²);双指针每次只动一个、每个元素至多被两端各访问一次 → 均摊 O(n)。精髓「不回头」:被排除的状态永久排除 | ⬜ |
| 3 | two_sum_sorted 怎么做?前提? | lo=0,hi=n-1;和小 lo++、和大 hi--、等返回。前提【数组有序】:每步能证明一端的数永久出局 | ⬜ |
| 4 | move_zeroes 快慢指针怎么做?slow/fast 各管什么? | slow=下一个非零该落定的位置;fast 探路。nums[fast]≠0 就 swap(nums[slow],nums[fast]),slow++。不变式:nums[0..slow-1] 永远是已就位非零段。O(n)/O(1) | ⬜ |
| 5 | 为什么 move_zeroes 不能遍历中 remove / 不能返回新数组? | list.remove 是 O(n) 且边遍历边改长度会跳元素 → O(n²)+错;新数组违反「原地」要求。`nums = ...` 重赋值只改局部变量指向,不算原地 | ⬜ |
| 6 | Python 一行交换两元素?Java 呢? | `a[i], a[j] = a[j], a[i]`(右边先打包元组再解包);Java 要临时变量三行 | ⬜ |
| 7 | LC11 盛水容器为什么移动【短】边? | 面积=宽×min(高),宽必然缩小,只有 min(高) 变大才有希望。移动长边:min 被短边卡死→只会更小,整批剪掉;移动短边:min 可能变大→有希望 | ⬜ |
| 8 | LC3 滑动窗口怎么维护? | 窗口 set 存已出现字符;for 右扩;若 s[right] 在 set 里 → while 左缩(remove s[left],left++);add(ch);best=max(best, 宽) | ⬜ |
| 9 | LC3 嵌套 while 为什么还是 O(n)? | right 只前进 n 次;left 全程总共 ≤ n 次(每个字符至多 add/remove 各一次)→ 总操作 ≤2n。数「元素总访问次数」,别数嵌套 | ⬜ |
| 10 | LC3 用 if 还是 while 收缩?窗口用 list 还是 set? | 必须 while(缩到无重复,if 只吐一个会残留);用 set(in/remove O(1)),list 退化 O(n²) | ⬜ |
| 11 | LC209 和 LC3 模板差在哪两点? | ① 合法条件:LC3「无重复」用 set,LC209「sum≥target」用 int;② 更新位置:求最长写 while 后(LC3),求最短写 while 内(LC209,每次迭代窗口都合法都要抢答) | ⬜ |
| 12 | LC209 为什么要求正整数?有负数怎么办? | 正数保证单调性:右扩 sum 只增、左缩只减,left 永不回头。有负数单调性破坏 → 换前缀和+单调队列(Ch36/37) | ⬜ |
| 13 | LC209 的「没找到」怎么处理? | best=float('inf') 哨兵,最后 `0 if best == inf else best`。别用 0/-1 当哨兵,会和合法答案混淆 | ⬜ |
| 14 | LC15 整体思路?复杂度? | sort → 固定 i → 对撞 lo/hi 找 -nums[i](退化成 two_sum_sorted)。O(n²)(外层 n × 内层 n;排序 O(nlogn) 被吸收) | ⬜ |
| 15 | LC15 有几处去重?各干嘛? | 两处。① 固定 i:`nums[i]==nums[i-1]` 跳过(同首数上一轮已找全);② 命中后 lo/hi 越过相邻重复值,再各走一步(忘走会死循环)。漏一处就有重复三元组 | ⬜ |
| 16 | LC15 去重①为什么和 i-1 比不和 i+1 比? | 和 i-1 比 = 跳过【已搜过的首数】;和 i+1 比 = 预判下轮会漏解(`[-1,-1,2]` 在 i=0 处被误跳)。口诀:看身后不看身前 | ⬜ |
| 17 | LC76 need[c] 的三种语义? | >0:t 还缺 c 这么多个;==0:刚好;<0:窗口里 c 冗余(左缩可放心丢) | ⬜ |
| 18 | LC76 为什么用 missing 整数不用 sum(need)? | 每次 while 都 sum 太慢。增量维护:右扩 need[ch]>0 才 missing-=1(冗余不补缺);左缩出窗口后 need 变正才 missing+=1 | ⬜ |
| 19 | LC76 为什么用 Counter 不用 dict? | Counter 访问不存在 key 返回 0(安全),dict 会 KeyError;Java 得 getOrDefault(c,0) 否则 NPE | ⬜ |
| 20 | LC76 哨兵 length 设什么?答案能取循环结束时的 left/right 吗? | length=len(s)+1,最后 `if length<=len(s)` 区分没找到。不能——循环结束的指针是最新窗口不是最优,要单独记 start/length | ⬜ |
| 21 | 滑动窗口通用模板三步? | ① 右扩纳入 s[right] ② 不合法/可优化就 while 左缩 ③ 更新答案(求最长在 while 后、求最短在 while 内) | ⬜ |
