## 🔖 闪卡

| # | 正面(问题) | 背面(答案) | 掌握 |
|---|---|---|---|
| 1 | 回溯的 Python 三行骨架? | `for 选择: path.append(x); dfs(); path.pop()`。append/pop 配对 = 做选择/撤销选择。Java 是 `list.add` + `list.remove(size-1)`,Python `pop()` 默认弹末尾更省心 | ⬜ |
| 2 | 回溯收集答案时最大的坑? | **必须 copy**!`res.append(path.copy())` 不是 `path`。直接收引用,后续 pop 会把已收的改没。这是回溯头号 bug | ⬜ |
| 3 | 全排列为什么用 used 数组,子集/组合用 start? | 全排列**顺序敏感**(元素可重复出现于不同位置)→ used 标记。子集/组合**只往后选**(start 下标)天然去重,不出现 [2,1]/[1,2] 重复 | ⬜ |
| 4 | 子集和全排列收集时机的区别? | 子集**每个节点都收**(进 dfs 第一行 `res.append(path.copy())`,含空集)。全排列**只收叶子**(`len(path)==n` 时)。因为子集任意长度都算答案 | ⬜ |
| 5 | 组合总和 LC39 为什么 dfs 传 i 不传 i+1? | 元素**可无限次重复用** → 下一层还能选当前元素 → 传 `i`。若每个只能用一次(LC40)才传 `i+1`。去重靠 start 下标「只往后选」 | ⬜ |
| 6 | 组合总和为什么要排序 + break 剪枝? | 排序后,循环里 `cand > remain` 时后面更大更不可能 → **break**(不是 continue)。不排序就不能 break,会白跑慢 | ⬜ |
| 7 | 股票 LC121 贪心的两个变量? | `min_price`(历史最低价,初值 `float('inf')`)+ `best`(最大利润,初值 0)。一次遍历:今天卖出算利润更新 best,再更新 min。O(n)/O(1) | ⬜ |
| 8 | Python 无穷大怎么写?和 Java 区别? | `float('inf')`(负无穷 `float('-inf')`)。Java 是 `Integer.MAX_VALUE`/`Double.POSITIVE_INFINITY`。Python 的 inf 参与减法不溢出,Java MAX_VALUE 减一下可能溢出,顺序敏感 | ⬜ |
| 9 | 跳跃游戏 LC55 贪心的关键洞察? | **可达位置是连续区间 [0, farthest]**——能到 k 就能到 0..k。维护 farthest,`i > farthest` 即 False,`farthest = max(farthest, i+nums[i])`,到末尾即 True。判断顺序:先 `i > farthest` 再更新 | ⬜ |
| 10 | 回溯/贪心/DP 怎么选型? | 要**所有方案**→ 回溯(全排列/子集/组合);要**一个最优解**且能证局部最优=全局最优 → 贪心(股票/跳跃);要最优但局部≠全局、有重叠子问题 → DP(Ch39 爬楼梯/零钱) | ⬜ |
| 11 | 回溯三兄弟对比表?(去重/递归参数/剪枝) | 全排列:used、无剪枝;子集:start、`dfs(i+1)`、无剪枝;组合:start、`dfs(i)`、排序+break。同一骨架 `for+append+dfs+pop`,差别在「何时收/传谁/剪不剪」 | ⬜ |
| 12 | target=0 时 combination_sum 返回啥? | `[[]]`(空组合是合法答案)。`remain==0` 立即收 `path.copy()`,此时 path 空。边界别忘了 | ⬜ |
